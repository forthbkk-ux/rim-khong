# แผนที่พิกัดหมู่บ้าน จ.หนองคาย  จ.บึงกาฬ จ.นครพนม

เว็บแอปพลิเคชันแผนที่แบบอินเทอร์แอคทีฟ สำหรับสืบค้นและปักหมุดพิกัดภูมิศาสตร์หมู่บ้านในเขตจังหวัดหนองคาย จังหวัดบึงกาฬ และจังหวัดนครพนม ครอบคลุม **10 อำเภอ 68 ตำบล รวม 795 หมู่บ้าน** โดยเชื่อมโยงและซิงค์ข้อมูลสดอัตโนมัติจาก Google Sheets พร้อมระบบติ๊กเลือกและส่งออกไฟล์ Excel (.xlsx)

---

## 📁 ไฟล์ภายในโฟลเดอร์

1. **`index.html`** - หน้าเว็บหลักของระบบแผนที่ (ดับเบิลคลิกเปิดใช้งานบนเบราว์เซอร์ Google Chrome, Edge ได้ทันที)
2. **`villages-data.js`** - ไฟล์ฐานข้อมูลพิกัดหมู่บ้านรูปแบบ JavaScript (795 หมู่บ้าน)
3. **`villages.json`** - ไฟล์ข้อมูลดิบรูปแบบ JSON (795 หมู่บ้าน)
4. **`README.md`** - เอกสารคู่มือการใช้งานระบบ

---

## 🌟 ฟังก์ชันและความสามารถเด่น

### 1. ระบบตัวกรองเมนู Drop down แบบหลายระดับ (Cascading Filters 4 ชั้น)
- **1. กรองจังหวัด (Province)**: เลือกจังหวัดที่ต้องการ เช่น จ.หนองคาย หรือเลือกดูทุกจังหวัด
- **2. กรองอำเภอ (District)**: กรองรายชื่ออำเภอตามจังหวัดที่เลือก เช่น **อำเภอโพนพิสัย** (159 หมู่บ้าน) หรือ **อำเภอเมืองหนองคาย** (181 หมู่บ้าน)
- **3. กรองตำบล (Subdistrict)**: กรองรายชื่อตำบลตามอำเภอที่เลือก โดยแสดงจำนวนหมู่บ้านในแต่ละตำบลครบทั้ง 27 ตำบล
- **4. เมนู Drop down ปักหมุดหมู่บ้าน (Village Pinning)**: 
  - จัดเรียงตามหมายเลขหมู่บ้านอย่างเป็นธรรมชาติ (หมู่ 1, หมู่ 2, ..., หมู่ 10, ...)
  - พร้อมระบุตำบลและอำเภอกำกับ เช่น `หมู่ 1 หนองกุ้งใต้ (ต.กุดบง อ.โพนพิสัย)`
  - เมื่อคลิกเลือกหมู่บ้าน แผนที่จะบิน (FlyTo) ไปยังพิกัดทันทีอย่างนุ่มนวล พร้อมปักหมุด กะพริบเน้นตำแหน่ง และเปิดหน้าต่าง Popup นำทางทันที
  - อัปเดตการ์ดข้อมูลและพิกัดภูมิศาสตร์ละเอียด 7 หลักทางแถบด้านซ้าย

### 2. หมุดแผนที่ขนาดกะทัดรัด เห็นชัดทุกหมู่บ้าน (Mini Pins & Permanent Labels)
- **ขนาดหมุดเริ่มต้นขนาดเล็ก (Mini Pin 18px)**: หมุดขนาดกะทัดรัด ไม่บดบังพื้นที่ ทำให้มองเห็นภาพรวมของทั้ง 340 หมู่บ้านได้พร้อมกัน
- **ระบุเลขหมู่บนหัวหมุด**: ทุกหมุดมีตัวเลขหมู่ระบุตรงกลางอย่างชัดเจน
- **ป้ายชื่อหมู่บ้านติดค้างถาวร (Permanent Labels)**: มีแถบป้ายชื่อสีขาวคมชัดลอยอยู่เหนือหมุดตลอดเวลา อ่านชื่อหมู่บ้านได้ทันทีโดยไม่ต้องคลิก
- **ปุ่มสลับขนาดหมุดแบบรวดเร็ว**: สามารถเลือกปรับขนาดหมุดได้ 3 ระดับ (เล็ก 18px / กลาง 24px / ใหญ่ 32px)
- **ปิดการรวมกลุ่มหมุด (No Cluster)**: ค่าเริ่มต้นปิดระบบรวมกลุ่มหมุด เพื่อให้เห็นหมุดเดี่ยวของทุกหมู่บ้านกระจายตัวอยู่บนแผนที่จริงอย่างครบถ้วน

### 3. ข้อมูลและการนำทาง Google Maps
- **พิกัด ละติจูด / ลองจิจูด**: แสดงทศนิยมชัดเจน 7 หลัก พร้อมปุ่ม **"คัดลอกพิกัด"** ในคลิกเดียว
- **ปุ่มนำทาง (Google Maps Directions)**: เปิด Google Maps เพื่อคำนวณเส้นทางและนำทางจากตำแหน่งปัจจุบันไปยังหมู่บ้านเป้าหมาย
- **ปุ่มเปิด Google Street View 360°**: สำรวจภาพทัศนียภาพรอบทิศทาง 360 องศาในพื้นที่จริง
- **ปุ่มระบุตำแหน่งปัจจุบัน (GPS My Location)**: สำหรับผู้ใช้งานที่ออกสำรวจภาคสนามด้วยมือถือหรือแท็บเล็ต

### 4. ระบบแสดงผลแผนที่ (Map Engines)
- **โหมด Google Tiles + Leaflet (ค่าเริ่มต้น - แนะนำ)**:
  - ดึงภาพถ่ายดาวเทียมความละเอียดสูงของ Google โดยตรง (Google Hybrid, Roadmap, Terrain และ OpenStreetMap)
  - **ไม่ต้องใช้ Google Maps API Key** เปิดไฟล์ใช้งานได้ทันที 100% ฟรี ไม่มีค่าใช้จ่าย
  - รองรับการสลับระหว่างมุมมองดาวเทียมและแผนที่ถนนได้ทันทีจากแถบควบคุมลอย
- **โหมด Google Maps JavaScript API (ทางการ)**:
  - มีหน้าต่างตั้งค่าให้กรอก Google Maps API Key เพื่อใช้งานเอนจินทางการ พร้อมมุมมอง 3D Tilt

### 5. สีประจำตำบล (Tambon Dynamic Color Coding)
ระบบแยกสีหมุดตามตำบลทั้ง 27 ตำบลด้วยจานสีที่สดใส คมชัด และคงที่:
- **อำเภอโพนพิสัย (11 ตำบล)**: กุดบง, จุมพล, ชุมช้าง, เซิม, ทุ่งหลวง, นาหนัง, บ้านผือ, บ้านโพธิ์, วัดหลวง, สร้างนางขาว, เหล่าต่างคำ
- **อำเภอเมืองหนองคาย (16 ตำบล)**: ในเมือง, มีชัย, โพธิ์ชัย, กวนวัน, คำพวง, ค่ายบกหวาน, จรเข้เผือก, ซอยสวรรค์, ดอนหญ้านาง, นาโป่ง, นาสมบูรณ์, ปะโค, พระธาตุบังพวน, สองคอน, หนองกอมเกาะ, หาดคำ
- มีแท็บ **"สีประจำตำบล"** ที่แสดงแถบสีและสถิติจำนวนหมู่บ้าน พร้อมคลิกเพื่อกรองหมุดตำบลนั้นๆ ได้ในคลิกเดียว

### 6. การค้นหาและระบบซิงค์ข้อมูล Google Sheets อัตโนมัติ (Live Auto-Sync)
- **ค้นหาด่วน (Live Search)**: ค้นหาได้ทั้งชื่อหมู่บ้าน, ตำบล, อำเภอ, จังหวัด หรือหมายเลขลำดับ
- **ซิงค์อัตโนมัติทันทีเมื่อเปิดหน้าเว็บ (Auto-Sync on Load)**: ดึงข้อมูลล่าสุดจาก Google Sheets ทันทีที่เปิดหน้าเว็บ
- **ซิงค์อัตโนมัติเมื่อสลับกลับมาที่แท็บ (Focus Auto-Sync)**: เมื่อมีการแก้ไขข้อมูลใน Google Sheets แล้วสลับหน้าต่างกลับมา แผนที่จะดึงข้อมูลใหม่ทันที
- **ซิงค์อัตโนมัติในเบื้องหลังทุก 60 วินาที**: อัปเดตข้อมูลสม่ำเสมอในขณะเปิดทิ้งไว้
- **เชื่อมต่อผ่าน Google Visualization API (JSONP)**: ทะลุข้อจำกัด CORS สามารถเปิดไฟล์ `index.html` บนเครื่อง (`file:///`) ได้โดยตรงโดยไม่ต้องรันเว็บเซิร์ฟเวอร์
- **ระบบสำรองข้อมูลออฟไลน์**: หากไม่มีอินเทอร์เน็ต ระบบจะใช้ฐานข้อมูลในเครื่อง 340 หมู่บ้านอัตโนมัติ ไม่ล่มแน่นอน

## 🚀 วิธีเปิดใช้งาน

1. ไปที่โฟลเดอร์ `อำโพนพิสัย` บน Desktop
2. ดับเบิลคลิกไฟล์ **`index.html`** เพื่อเปิดด้วย Google Chrome, Microsoft Edge หรือเบราว์เซอร์ใดก็ได้
3. ใช้งานเมนูปักหมุด กรองจังหวัด/อำเภอ/ตำบล หรือพิมพ์ค้นหาหมู่บ้านได้ทันที!
